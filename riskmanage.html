有人受傷、火災、冒煙、昏倒或立即危險時，先打 119／110，不必等待主管同意。

01｜事件分級

第1級｜一般異常現場可修正、損失小、不影響安全。完成處理後留下紀錄。
第2級｜重要異常可能影響營業、商品、設備或客訴。通知店長並控制損失。
第3級｜緊急事件涉及人身、火災、政府機關、重大財損。立即通知負責人。

02｜所有事件統一照這5步

1. 保護人員
2. 停止損失
3. 保留證據
4. 通知店長
5. App回報

03｜緊急處理卡

🔥 火災、冒煙、焦味
  1. 立即疏散人員。
  2. 安全情況下關閉相關設備或區域電源。
  3. 有明火或大量冒煙，立即打119。
  4. 封鎖區域，避免人員靠近。
  5. 通知店長與負責人。
不要為了找原因延誤撤離。
🩹 人員受傷或昏倒
  1. 確認現場安全與人員意識。
  2. 必要時立即打119。
  3. 不要任意移動疑似骨折或重傷者。
  4. 保留現場照片與監視器時間。
  5. 通知店長與負責人。
不要先討論責任或承諾賠償。
⚡ 停電或跳電
  1. 確認是單一設備、局部或全店停電。
  2. 不要反覆強行送電。
  3. 依配電標示關閉疑似故障設備。
  4. 優先維持冷凍、冷藏設備。
  5. 聯絡水電並通知負責人。
不要自行拆開配電盤。
❄️ 冷凍冷藏故障
  1. 查看設備溫度，減少開門。
  2. 優先移轉高價與易變質商品。
  3. 拍攝溫度與商品狀況。
  4. 聯絡冷凍冷藏廠商。
  5. 由店長判斷是否停售。
不要先丟掉商品或破壞現場。
🥫 食品異物或變質
  1. 立即停售同批商品。
  2. 保留商品、包裝、批號與進貨資料。
  3. 記錄客戶反映內容與聯絡方式。
  4. 拍照並通知店長。
  5. 由負責人決定回收、送驗或回覆。
不要丟棄樣品，也不要直接承認責任。
💬 客訴或要求賠償
  1. 先完整聽完並記錄客戶訴求。
  2. 取得商品、發票、照片與聯絡方式。
  3. 告知公司會查明後回覆。
  4. 保留相關商品與監視器時間。
  5. 通知店長與負責人。
不要爭辯、承認法律責任或承諾高額賠償。
💰 現金或帳款異常
  1. 立即重新點算。
  2. 核對POS、發票、刷卡與交班紀錄。
  3. 記下相關監視器時間。
  4. 通知店長。
  5. 大額或無法查明時通知負責人。
不要公開指控員工，也不要私下補款結案。
🏛️ 政府機關到場
  1. 確認對方單位與身分。
  2. 請對方說明檢查目的。
  3. 立即通知店長與負責人。
  4. 依法配合必要檢查。
  5. 保留公文、名片與檢查結果。
不要猜測、亂回答或自行簽署不清楚的文件。
